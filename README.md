# An-lise-Multimodal-de-Imagens-M-dicas-com-MedGemma
Este repositório contém uma implementação em Python para realizar análises clínicas preliminares e descrições visuais de imagens médicas (como lesões dermatológicas) utilizando o modelo multimodal de IA MedGemma  via biblioteca `transformers` da Hugging Face.
